# G1-042 Instagram投稿

## カルーセル投稿（8枚構成）

---

### スライド1（表紙）
**テキスト：**
```
父の日のプレゼント
自分のお金で買えた
初めての年の話
```
**デザイン指示：** 温かみのある室内背景。スマホを持つ女性シルエット。フォント大きめ・白抜き。

---

### スライド2
**テキスト：**
```
専業主婦5年目
自分だけのお金は
ずっとゼロでした
```
**デザイン指示：** シンプル白背景。グレーフォント。共感を引き出す静かなトーン。

---

### スライド3
**テキスト：**
```
父の日が近づくたびに
"これ買っていい？"を
夫に聞いていた

夫のお金で夫にプレゼント
なんかおかしいな、と思った
```
**デザイン指示：** 少し薄いオレンジ背景。感情的な文章を中央配置。

---

### スライド4
**テキスト：**
```
去年の父の日の夜
SNSで見た投稿がきっかけで

在宅でできる仕事を
調べてみた
```
**デザイン指示：** スマホ画面を見ている手元のイメージ。夜の暗めトーン。

---

### スライド5
**テキスト：**
```
チャットレディ
顔出しなし・本名なし
スマホ1台で完結

最初は半信半疑だったけど
登録3分・無料だから
試してみた
```
**デザイン指示：** 明るい清潔感ある背景。チェックリスト風レイアウト。

---

### スライド6
**テキスト：**
```
最初の月

子どもの昼寝の30分
夜の1〜2時間だけで

3万円を超えた
```
**デザイン指示：** 数字「3万円」を大きく強調。グリーン系アクセント。

---

### スライド7
**テキスト：**
```
今年の父の日

自分のお金で
5,000円の財布を買った

"使っていい？"を
誰にも聞かなかった
```
**デザイン指示：** 温かみのある写真風背景。感情的な締めくくり。フォント少し大きめ。

---

### スライド8（CTA）
**テキスト：**
```
父の日まであと3週間

登録3分・無料
退会はいつでもOK

まず試してみるだけでいい
↓プロフのリンクから
```
**デザイン指示：** 明るいアクションカラー（オレンジ or 紫）。矢印アイコン使用。CTA強調。

---

## キャプション

父の日のプレゼント、ずっと夫のお金で買ってた。

「使っていい?」って聞くたびに、なんか違うな…って思ってたけど、自分のお金がないからそれしかできなかった。

去年の父の日をきっかけに動いて、今年は初めて自分のお金でプレゼントを買えました。
5,000円の財布。たったそれだけだけど、今まで一番気持ちよかったプレゼントでした。

やり方はプロフのリンクに全部書いてます。
