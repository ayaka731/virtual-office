# G1-042 TikTok台本

**テーマ：** 父の日プレゼントを自分のお金で買えた話
**尺：** 60秒
**想定視聴者：** 専業主婦・育児中主婦 30〜40代

---

## フック（0〜3秒）

**映像：** テロップのみ。白背景に黒文字。

**テロップ（大きく）：**
```
「使っていい?」を
夫に聞き続けた5年間
```

**ナレーション（テロップと同時）：**
「父の日のプレゼント代、ずっと夫に聞いてた話します。」

---

## 本編①：共感（3〜15秒）

**映像：** 部屋着の女性がスマホを持ちながら考えているイメージ（テロップ中心で可）

**テロップ：**
```
専業主婦5年目
自分のお金はゼロ

父の日のプレゼントを買いたくて
「これ使っていい？」を夫に聞いた

夫のお金で夫にプレゼントって
なんか違うな、って思って
```

**ナレーション：**
「専業主婦5年目で、自分のお小遣いってずっとゼロだったんです。父の日のプレゼントを買うたびに夫に確認して。夫のお金で夫にプレゼントって、なんかおかしいな、ってある日急に気づいて。」

---

## 本編②：転機（15〜30秒）

**映像：** スマホを夜見ているシーン演出

**テロップ：**
```
去年の父の日の夜
SNSで「在宅でできる仕事」を見た

顔出しなし・声なし
スマホ1台で完結

半信半疑で調べてみた
```

**ナレーション：**
「去年の父の日の夜に、SNSで在宅でできる仕事の投稿を見たんです。顔出しなし、声も出さなくていい、スマホだけで完結って書いてあって。本当かな、と思いながら調べてみました。」

---

## 本編③：体験（30〜48秒）

**映像：** 数字テロップを強調

**テロップ：**
```
子どもの昼寝の30分
夜の1〜2時間だけで

最初の月
3万円を超えた

3ヶ月続けたら
10万円に近づいてきた
```

**ナレーション：**
「子どもの昼寝の時間と、夜の1〜2時間だけで、最初の月に3万円を超えました。正直びっくりした。3ヶ月続けた今は、月10万円に近づいてきてる感じがあります。」

---

## クライマックス（48〜56秒）

**映像：** テロップ強調。感情的な一文。

**テロップ（フォント大きめ）：**
```
今年の父の日は
自分のお金でプレゼントを買った

「使っていい？」を
誰にも聞かなかった
```

**ナレーション：**
「今年の父の日は、自分のお金で財布を買いました。誰にも確認しなかった。それだけで、すごく気持ちよかった。」

---

## CTA（56〜60秒）

**テロップ：**
```
父の日まであと3週間
登録3分・無料・退会自由

気になったらプロフのリンクから
```

**ナレーション：**
「父の日まであと3週間あります。登録は3分で無料です。気になったらプロフのリンクを見てみてください。」

---

## 撮影・編集メモ

- テロップ中心構成（ナレーションなし版でも成立するよう設計）
- BGM：ゆったり系・主婦共感系（著作権フリー）
- カラー：温かみのある白・クリーム系
- 直接的な「チャットレディ」表現は避け「在宅でできるお仕事」「スマホ1台の在宅仕事」に言い換え済み
- 「稼げる」断言なし・個人体験として語る構成 ✓
