# X投稿原稿 - G1-003（チャットレディ 確定申告）

---

## メイン投稿（スレッド形式）

**ツイート①（アイキャッチ）:**
```
チャットレディで稼いだお金、
確定申告が必要か知ってる？

実は「年間20万円以上の所得」が
会社員の申告義務ラインです📋

税金まわりを知っておくと
✅ 余計な追徴課税を防げる
✅ 経費で税負担を減らせる
✅ 会社バレのリスクも下げられる

スレッドで詳しく解説します👇
```

**ツイート②（経費情報）:**
```
チャットレディの経費、
こんなものが計上できます↓

📱 スマホ・通信費（仕事割合分）
💡 照明・撮影機材（100%）
👗 衣装・コスチューム（100%）
💄 ヘアメイク用品（業務目的のもの）

仕事専用スマホがあると
通信費を100%経費にできてお得✨

「収入−経費」が所得の計算なので
経費が増えるほど税負担が減ります
```

**ツイート③（住民税対策）:**
```
会社員チャトレさん必読📌

副業がバレる主な原因は
「住民税の増額通知」

確定申告書の第二表で
「住民税を自分で納付（普通徴収）」
を選択するだけで対策できます

完全に防げるわけではないけど
リスクを大幅に下げられる方法です
```

**ツイート④（CTA）:**
```
まず何より大事なのは
「信頼できるサービスで始める」こと

安全対策が充実している
チャットレディサービスを比較↓

#PR #チャットレディ #副業 #在宅ワーク #確定申告

※本記事にはアフィリエイトリンクが含まれます
```

✅ 雑所得 → 副業規模なら多くはこれ
