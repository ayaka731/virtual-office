# キーワードリサーチスキル（データ分析・ケンタ）

## 役割
企画長が選定したテーマに対し、SEO的に攻略可能なKW戦略を立てる。

## 実行手順

### 1. メインKWの深掘り
- メインKWの関連語・共起語を洗い出す
- 「○○とは」「○○ メリット」「○○ デメリット」等のロングテールを展開
- 疑問形KW（「○○って何？」「○○は安全？」）を抽出

### 2. 記事構成への反映
KWリストから、以下のH2見出し候補を生成する：
- 各H2にサブKWを1つずつ割り当てる
- H2の順番は検索意図の流れに沿う（知る→比較→行動）
- H2は5〜8個を目安

### 3. 出力フォーマット
```json
{
  "main_kw": "メインKW",
  "long_tail_kws": ["ロングテール1", "ロングテール2"],
  "question_kws": ["疑問形KW1", "疑問形KW2"],
  "suggested_h2": [
    {"heading": "H2見出し案", "assigned_kw": "割当KW", "intent": "情報/比較/行動"}
  ],
  "internal_link_suggestions": ["関連記事テーマ案"]
}
```
