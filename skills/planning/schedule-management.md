# スケジュール管理スキル（カレンダー管理・ユイ）

## 役割
投稿スケジュールを管理し、最適なタイミングで投稿を実行する。

## 投稿頻度目標

| ジャンル | note | X | Instagram | TikTok |
|---|---|---|---|---|
| G1 | 週3本 | 毎日1〜3投稿 | 週3本 | 週2本 |
| G2 | 週3本 | 毎日1〜3投稿 | 週3本 | 週2本 |

## 最適投稿時間帯

| プラットフォーム | 平日ベスト | 休日ベスト |
|---|---|---|
| note | 7:00 / 12:00 / 20:00 | 10:00 / 20:00 |
| X | 7:00 / 12:00 / 18:00 / 22:00 | 10:00 / 15:00 / 21:00 |
| Instagram | 12:00 / 18:00 / 21:00 | 11:00 / 15:00 / 20:00 |
| TikTok | 12:00 / 19:00 / 22:00 | 11:00 / 16:00 / 21:00 |

## スケジュール管理ルール
- 同ジャンルの記事は連続投稿しない（G1→G2→G1のローテーション）
- noteの投稿後30分以内にXでスレッド投稿（導線）
- Instagramはnoteと同日か翌日
- TikTokは独立スケジュール（台本完成次第）
- セール時期やイベント時は投稿頻度を2倍にする

## 出力フォーマット
```json
{
  "article_id": "G1-001",
  "schedule": {
    "note": "YYYY-MM-DD HH:MM",
    "x": "YYYY-MM-DD HH:MM",
    "instagram": "YYYY-MM-DD HH:MM",
    "tiktok": "YYYY-MM-DD HH:MM"
  },
  "notes": "スケジュールに関する補足"
}
```
