# トレンド分析スキル（企画長・ミサキ）

## 役割
ジャンルごとのトレンドを分析し、今書くべきテーマを決定する。

## 実行手順

### 1. キーワード候補の生成
対象ジャンルに基づき、以下の切り口でKW候補を20個生成する：
- 「悩み系」：○○ 不安 / ○○ 怖い / ○○ 大丈夫
- 「ハウツー系」：○○ 始め方 / ○○ やり方 / ○○ コツ
- 「比較系」：○○ おすすめ / ○○ ランキング / ○○ 比較
- 「体験談系」：○○ 体験談 / ○○ 口コミ / ○○ 実際

### 2. KW選定基準
以下を総合判断してメインKWを1つ、サブKWを3〜5つ選定：
- 検索意図が明確か
- 競合の強さ（企業サイトばかりなら避ける）
- マネタイズとの相性（アフィリンクに繋げやすいか）
- 季節性（今がタイミングか）

### 3. ジャンル別テーマ方針

#### G1（チャトレ・メルレ）
優先テーマカテゴリ：
- 初心者向け始め方ガイド
- サイト比較・ランキング
- 安全性・身バレ対策
- 収入リアル体験談
- 確定申告・税金関連
- スマホだけでOK系

#### G2（Amazonアソシエイト）
優先テーマカテゴリ：
- 季節商品レビュー（今月〜来月に需要が来るもの）
- 定番商品の比較記事
- 「買ってよかった」系まとめ
- セール情報（プライムデー等）
- カテゴリ特化（ガジェット/生活用品/美容等）

### 4. 出力フォーマット
```json
{
  "theme": "テーマ名",
  "genre": "G1 or G2",
  "target_keyword": "メインKW",
  "sub_keywords": ["サブKW1", "サブKW2", "サブKW3"],
  "search_intent": "情報収集 / 比較検討 / 行動（購入・登録）",
  "article_type": "体験談 / 比較 / ハウツー / ランキング / レビュー",
  "target_persona": {
    "age": "20代後半〜30代",
    "situation": "具体的な状況",
    "pain_point": "抱えている悩み",
    "desired_outcome": "どうなりたいか"
  },
  "monetization_point": "アフィリンクをどこに置くか",
  "urgency": "high / medium / low",
  "estimated_volume": "推定月間検索ボリューム感"
}
```
