# Web調査スキル（調査官・ハルカ）

## 役割
企画部から受け取ったテーマについて一次情報を収集する。

## 実行手順

### 1. 情報収集対象
- 対象サービスの公式サイト情報
- 最新のキャンペーン・報酬体系
- ユーザーの口コミ・体験談（Yahoo知恵袋、X、note等）
- 関連ニュース・プレスリリース

### 2. G1固有の調査項目
- 各チャトレ・メルレサイトの報酬体系
- 登録要件（年齢、身分証明等）
- アプリの有無、使い勝手
- 退会方法の簡便さ
- 安全対策（身バレ防止機能等）

### 3. G2固有の調査項目
- 商品の最新価格
- レビュー件数・平均評価
- 類似商品との差別化ポイント
- セール履歴・価格推移
- Amazonベストセラーランキングの変動

### 4. 出力フォーマット
```json
{
  "theme": "テーマ名",
  "research_date": "YYYY-MM-DD",
  "key_findings": [
    {"fact": "発見した事実", "source": "情報源", "reliability": "high/medium/low"}
  ],
  "user_voices": [
    {"quote_summary": "口コミ要約", "sentiment": "positive/negative/neutral", "source": "出典"}
  ],
  "latest_info": "最新のキャンペーンや変更点",
  "data_points": ["使える数値データ"]
}
```
