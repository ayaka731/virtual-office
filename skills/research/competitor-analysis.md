# 競合分析スキル（競合分析・タクミ）

## 役割
同テーマで上位表示されている競合記事を分析し、それを上回る構成を提案する。

## 実行手順

### 1. 競合記事の分析項目
- タイトルの構造（文字数、KW位置、数字の有無）
- H2/H3の見出し構造（何本、どんな順番か）
- 記事の総文字数
- アフィリンクの配置箇所と個数
- 画像・表・リストの使用状況
- CTAの位置と文言
- 内部リンクの本数

### 2. 差別化ポイントの特定
競合記事に「ないもの」を見つける：
- 最新情報（競合が古い情報のまま）
- 具体的な数字やデータ
- 体験談・実例
- 図解やまとめ表
- FAQ（よくある質問）セクション

### 3. 出力フォーマット
```json
{
  "competitors": [
    {
      "title": "競合タイトル",

      "word_count": 3000,

      "strengths": ["強み"],
      "weaknesses": ["弱み・足りない部分"]
    }
  ],
  "differentiation_strategy": "差別化の方針",
  "recommended_structure": {
    "title_template": "タイトル案",
    "h2_structure": ["推奨H2構成"],
    "target_word_count": 3500,
    "unique_sections": ["競合にない独自セクション"]
  }
}
```
