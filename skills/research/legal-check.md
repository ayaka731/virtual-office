# 法規制チェックスキル（ファクトチェック・リン）

## 役割
記事のテーマ段階で法規制リスクを事前チェックし、NGワード・NG表現を明示する。

## G1（チャトレ・メルレ）の法規制チェックリスト

### 景品表示法
- [ ] 「必ず稼げる」「確実に○万円」等の断定表現がないか
- [ ] 「誰でも簡単」等の不当表示に該当しないか
- [ ] 体験談に「※個人の感想です。効果を保証するものではありません」の注記指示があるか
- [ ] 収入例を出す場合「※収入を保証するものではありません」の注記指示があるか

### 特定商取引法
- [ ] 広告であることを明示しているか（PR / 広告 / アフィリエイト表記）
- [ ] 記事冒頭またはアフィリンク直前にPR表記があるか

### プラットフォーム規約
- [ ] note：成人向けコンテンツガイドラインに抵触しないか
- [ ] X：センシティブコンテンツに該当しないか
- [ ] Instagram：コミュニティガイドラインに抵触しないか
- [ ] TikTok：成人向けテーマの制限に抵触しないか

### NGワード・NG表現リスト（G1）

**絶対NG：**
- 「必ず稼げる」「月収保証」「リスクゼロ」「100%安全」
- 「誰でも」「簡単に」「すぐに」（収入に関する文脈で）
- 性的なコンテンツの直接的な描写
- 未成年を想起させる表現

**要注意（文脈次第でNG）：**
- 「高収入」→ 「収入の目安」に言い換え
- 「稼げる」→ 「収入を得られる可能性がある」に言い換え
- 「安全」→ 「安全対策が充実している」に言い換え

## G2（Amazonアソシエイト）の法規制チェックリスト

### Amazonアソシエイト規約
- [ ] 「Amazon.co.jpアソシエイト」の表記があるか
- [ ] 価格は「※価格は記事作成時点のものです」の注記があるか
- [ ] アソシエイトリンクであることの開示があるか
- [ ] 商品画像のキャッシュ・保存をしていないか（直リンク必須）

### 景品表示法
- [ ] 「最安値」「業界最高」等の最上級表現に根拠があるか
- [ ] 比較記事の基準が明確か
