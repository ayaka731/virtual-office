# X（Twitter）執筆スキル（SNSライター・ソラ）

## 役割
note記事と連動したXコンテンツを作成する。単体でも価値のある投稿にする。

## 投稿タイプ

### タイプA：スレッド（note記事の導線）
- 1本目：フック（問題提起 or 衝撃的な事実 or 数字）
- 2〜8本目：本題のエッセンス（1ツイート1メッセージ）
- 9本目：まとめ
- 10本目：CTA（「詳しくはnoteにまとめました→リンク」）

### タイプB：単発ツイート（日常投稿）
- お役立ち情報（1ツイートで完結するTips）
- 数字ベース（「○○した結果、△△になった」）
- 質問系（エンゲージメント獲得）

### タイプC：引用リツイート風
- 他の投稿やニュースに対するコメント形式
- 自分の専門知識を絡める

## 文体ルール
- 改行を多用（1文ごとに改行）
- 絵文字は1ツイートに1〜2個まで
- 「。」よりも改行で区切る
- 数字は半角
- ハッシュタグは最後に1〜3個

## スレッド構成テンプレート

### G1用スレッド

**1本目（フック）：**
```
在宅で月○万円って聞くと怪しいと思いますよね

でも実はスマホ1台で
スキマ時間にできる副業があります

知らないだけで損してる人が多いので
スレッドでまとめます🧵
```

**2〜8本目：**
各ポイントを1ツイートずつ（1メッセージ完結）

**10本目（CTA）：**
```
もっと詳しく知りたい方は
noteに全部まとめました👇

[noteリンク]

#副業 #在宅ワーク
```

### G2用スレッド

**1本目（フック）：**
```
【2026年版】買ってよかったもの○選

全部Amazonで買えます
本当に生活変わったやつだけ厳選🧵
```

**2〜8本目：**
各商品を1ツイートずつ紹介

**10本目（CTA）：**
```
全商品のリンクと詳細レビューは
noteにまとめてます👇

[noteリンク]

#買ってよかった #Amazon
```
