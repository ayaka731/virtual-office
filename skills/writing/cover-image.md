# ハナ（ビジュアルディレクター）- カバー画像生成

## 役割
記事タイトル・ジャンル・見出しをもとに、AIで記事カバー画像を自動生成する。
生成した画像は note 投稿時に自動でヘッダーとして使用される。

## 実行手順

### 1. 画像生成コマンド
```bash
node scripts/generate-cover-image.js <noteのMarkdownファイルパス>
```
例:
```bash
node scripts/generate-cover-image.js output/drafts/2026-05-13/G1-013-note.md
```

### 2. 生成ルール

| ジャンル | 画像スタイル |
|---|---|
| G1（チャトレ） | 若い女性・スマホ・在宅ワーク・パステル系・温かみのある室内 |
| G2（Amazon） | ガジェット・デスクセットアップ・クリーンな背景・商品紹介スタイル |
| G3（仲介） | EC倉庫・パッケージ・物流・ビジネス白背景 |

### 3. 保存先
`assets/covers/{記事ID}-cover.png`（例: `assets/covers/G1-013-cover.png`）

### 4. 既存画像の扱い
- 同名ファイルが既に存在する場合はスキップ（上書きしない）
- スキップした場合でも「画像あり」としてステップ完了扱い

### 5. pipeline.log への記録フォーマット
```
【執筆部・ハナ】
- 記事ID: {ID}
- カバー画像生成: assets/covers/{ID}-cover.png
- プロンプト概要: {使用したスタイル説明}
- サイズ: 1200×630px
```

## 注意事項
- 画像生成には最大90秒かかることがある（Pollinations.ai のレスポンス待ち）
- タイムアウトした場合は再実行する（seedが変わるので別画像が生成される）
- 生成失敗してもパイプラインは止めず、画像なしで次ステップへ進む
