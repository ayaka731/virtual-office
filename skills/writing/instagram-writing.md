# Instagram執筆スキル（SNSライター・ソラ兼任）

## 役割
Instagram用のキャプション、ハッシュタグ、画像テキスト指示を作成する。

## 投稿タイプ

### カルーセル投稿（メイン）
- 1枚目：アイキャッチ（タイトル＋フック）
- 2〜9枚目：本題（1スライド1メッセージ）
- 10枚目：CTA（保存・フォロー・プロフリンク誘導）

### リール台本
- 15〜60秒の台本
- テロップ原稿付き
- TikTok台本と共通化可能

## キャプションルール
- 1行目がフック（改行で区切る）
- 本文は改行多め（読みやすさ重視）
- 絵文字は見出し的に使う（✅ 📌 👇等）
- CTAを最後に必ず入れる
- 「保存してね」の促し

## ハッシュタグ戦略
合計20〜30個を3カテゴリで構成：
- 大（10万投稿以上）：5〜8個
- 中（1万〜10万）：10〜12個
- 小（1万未満のニッチ）：5〜8個

### G1用ハッシュタグ例
**大：** #副業 #在宅ワーク #副業初心者 #在宅副業 #スマホ副業
**中：** #在宅ワークママ #副業女子 #スキマ時間副業 #主婦副業
**小：** #チャットレディ初心者 #メールレディ始め方 #在宅チャット

### G2用ハッシュタグ例
**大：** #Amazon #買ってよかった #おすすめ商品 #暮らしを整える
**中：** #Amazon購入品 #ガジェット好き #便利グッズ
**小：** 商品カテゴリごとに変動

## 画像テキスト指示フォーマット
```json
{
  "slide_1": {
    "type": "cover",
    "main_text": "表示するタイトル（15文字以内）",
    "sub_text": "サブテキスト（10文字以内）",
    "style": "太字・中央配置・背景色指定"
  },
  "slide_2": {
    "type": "content",
    "heading": "見出し",
    "body": "本文テキスト（40文字以内）",
    "icon": "使用アイコンの説明"
  }
}
```

## 出力フォーマット

```
【キャプション】
テキスト本文

【ハッシュタグ】
#タグ1 #タグ2 ...

【画像テキスト指示】
スライド1〜10の指示
```
