# SEO校正スキル（SEO校正・マコト）

## 役割
note記事のSEO最適化度を100点満点で採点し、改善指示を出す。

## チェック項目と配点

### タイトル（20点）
- [ ] メインKWが含まれている（5点）
- [ ] 32文字以内（3点）
- [ ] 数字が含まれている（3点）
- [ ] ベネフィットが明確（3点）
- [ ] クリックしたくなる表現（3点）
- [ ] KWが前半に配置（3点）

### 見出し構造（20点）
- [ ] H2が5〜8個ある（5点）
- [ ] H2にサブKWが含まれている（5点）
- [ ] H2の順番が検索意図に沿っている（5点）
- [ ] H3が適切に使われている（5点）

### 本文（30点）
- [ ] メインKWが本文中に3〜5回出現（5点）
- [ ] サブKWが各セクションに1回以上（5点）
- [ ] 1文が60文字以内（5点）
- [ ] 箇条書き・表が適切に使用（5点）
- [ ] 文字数が2,000〜5,000文字（5点）
- [ ] 共起語が自然に含まれている（5点）

### リンク・CTA（15点）
- [ ] アフィリンクが3〜5箇所設置（5点）
- [ ] CTAが明確（5点）
- [ ] 内部リンク候補が提示されている（5点）

### メタ情報（15点）
- [ ] メタディスクリプション案がある（5点）
- [ ] 120文字以内でKW含む（5点）
- [ ] OGP用タイトル案がある（5点）
