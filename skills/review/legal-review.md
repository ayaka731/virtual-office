# 法務校正スキル（法務チェック・サクラ）

## 役割
完成した記事に法規制違反がないかを最終チェックする。

## チェック手順

### 1. NG表現スキャン
`skills/research/legal-check.md` で定義されたNGワードリストと照合し、該当表現を全て抽出する。

### 2. PR表記チェック
- 記事冒頭にPR表記があるか
- アフィリンク付近にPR表記があるか
- 表記形式：「※本記事にはアフィリエイトリンクが含まれます」または「PR」

### 3. 免責事項チェック
- 収入に関する記述に「※個人の感想です」があるか
- 価格に関する記述に「※記事作成時点」があるか
- 効果・効能に関する断定がないか

### 4. プラットフォーム別チェック
各プラットフォームのガイドラインに抵触する表現がないか確認。

## 判定基準
- **high** → 1つでもあれば即REJECT（修正必須）
- **medium** → 2つ以上あればREVISE
- **low** → 注意喚起のみでGO可能

## 出力フォーマット
```json
{
  "legal_risk": "low / medium / high",
  "violations": [
    {"type": "景品表示法", "expression": "該当表現", "location": "記事内の位置", "fix": "修正案"}
  ],
  "missing_disclaimers": ["不足している免責事項"],
  "platform_issues": {
    "note": "問題なし or 問題内容",
    "x": "問題なし or 問題内容",
    "instagram": "問題なし or 問題内容",
    "tiktok": "問題なし or 問題内容"
  },
  "verdict": "GO / REVISE / REJECT"
}
```
